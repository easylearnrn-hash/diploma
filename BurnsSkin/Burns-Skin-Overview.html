NCLEX Top Priorities — Burns & Skin

  • 🔥 Burns → AIRWAY first → then fluids (Parkland) → then pain (IV only)
  • 🩹 Pressure ulcers → reposition every 2 hrs → high-protein diet
  • 🦠 Cellulitis → mark borders → antibiotics → watch for sepsis
  • 👁️ Eye swelling + eye movement pain = orbital cellulitis = EMERGENCY
  • 🧪 Red streaks on skin = lymphangitis = call provider STAT
  • 💊 SJS = stop the drug immediately = treat like burns
  • 🌙 Night itch + burrow lines = scabies = Permethrin 5%
  • 🔬 ABCDE mole changes = melanoma = urgent dermatology referral
