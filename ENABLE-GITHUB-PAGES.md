## 🚀 Final Step: Enable GitHub Pages (2 minutes)

### Step 1: Go to Repository Settings
Click this link:
👉 **https://github.com/easylearnrn-hash/diploma/settings/pages**

### Step 2: Configure GitHub Pages
1. Under "Build and deployment"
2. **Source:** Deploy from a branch
3. **Branch:** Select `main`
4. **Folder:** Select `/ (root)`
5. Click **"Save"**

### Step 3: Wait 2-3 Minutes
GitHub will build and deploy your site. You'll see a message:
> "Your site is live at https://easylearnrn-hash.github.io/diploma/"

## 🔧 Troubleshooting

### If GitHub Pages isn't enabled yet:
Just follow Step 1-2 above - takes 30 seconds!

### If you see "404 - Page not found":
Wait 2-3 minutes for GitHub to deploy. Refresh the page.

### If VID loads but shows "Loading..." forever:
1. Check Supabase is running: https://supabase.com/dashboard/project/zlvnxvrzotamhpezqedr
2. Verify RLS policies allow anonymous access to `students` table

### If you want to use a custom domain:
1. Add a file named `CNAME` with your domain (e.g., `vid.acnhs.edu`)
2. Configure DNS to point to GitHub Pages
3. VID will be at: `https://vid.acnhs.edu/VID.html`
